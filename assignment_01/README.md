## 1. Project Description

This project is a multi-page Book Store website developed for the Web Technologies course. It is inspired by the following WordPress demo:

https://websitedemos.net/book-store-02/

The website demonstrates HTML5, CSS3, Flexbox, Grid, forms, selectors, media elements and responsive web design.

## 4. How to Run

1. Open the project folder in VS Code.
2. Install the Live Server extension.
3. Open `index.html`.
4. Right-click and select Open with Live Server.
5. Use the navigation menu to visit other available pages.
